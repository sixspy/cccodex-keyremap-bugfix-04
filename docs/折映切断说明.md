# 折映双正式切断说明

- 锁定日期：2026-11-20（当天禁止改口）
- 决策：折映双正式缺陷按 **乙路径** 切断
- 互斥：甲、乙两路只能选一种，不得混用；本仓实现固定为乙路径

## 甲路径（不采用）

同新键第二次插入前查重不通过，则整笔拒绝，正式区零增，并写“争用”。

不采用原因：映射册已有“多对一”类型（`OLD-B1`、`OLD-B2 → NEW-200`），
甲路径会把第二个合法来源整笔拒掉，来源丢失，与“多旧键折到同一新键”的产品行为冲突。

## 乙路径（采用，唯一落库口径）

1. 同一新键在正式区只保留一行。
2. 第二次及以后折入的旧键写入来源旁表 `formal_sources`，不新增正式行。
3. 正式行与旁表写入处于同一事务；任一步失败，正式与旁表一起回滚。
4. 每次折映写一条 `remap_receipts` 回执；回执与正式、旁表、映射册、互证卡同态。
5. 正式区、来源旁表、映射册、互证卡、折映回执五处必须同态；只做展示合并视为失败。

## 键锁与争用

- 同一新键的折映必须占用键锁（单进程内存锁，本地 SQLite 夹具单 worker）。
- 两路同时折同一新键时，先到者持锁落库；后到者只写一条“争用”冲突与“争用”回执，不改正式、不改旁表。

## 偏离保护

- 代码常量 `CUT_PATH` 必须为“乙”。
- 若被改成甲路径或其它值，折映写路径一律拒写，并记“折映偏了”冲突与“拒绝”回执。
- 禁止只改去重提示文案；禁止只改展示合并。
